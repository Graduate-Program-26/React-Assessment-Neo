# Github Personal Dashboard
---

## Features

- User authetification using OAuth
- Display Github user information (User, Repo Activities/Event )
- Search for specific user 

---

## Technology Stack

- Next.js
- Tailwind
- ReactJs
- OAuth
- DaisyUI
